## Software

### Free

- [Embroidery Pricing Calculator](https://embroiderypricingcalculator.com) - Free online calculator for embroidery job pricing (stitches, fabric, and labor).
- [Ink/Stitch](https://inkstitch.org) - An open-source machine embroidery design platform based on [Inkscape](https://inkscape.org).
